📖 核心流程说明

#流程路径
①流程图编辑→执行画布编辑 → Store → IPC('engine:start') → spawnPython(engine.py) → DSLParser → Executor → 逐节点执行 → stdout 事件回调 → Store 更新 → 画布高亮
②AI Agent 执行AgentView 输入目标 → IPC('agent:start') → spawnPython(agent) → AgentConfig 解析 → _unified_run() → Planner(生成步骤) / ReAct(逐步骤) → 监督执行(焦点/定位/执行/OCR验证) → 步骤结果回传 → 前端展示进度
③HTTP API 远程控制Claude Code / curl → api.ts:7880 → ipcRenderer.send('api-command') → Store.dispatch → 前端更新 → GET /api/get-state 返回当前状态
④MCP 工具调用外部 MCP 客户端 → stdio JSON-RPC → mcp/server.py → FeatureRegistry → @feature 函数执行 → 结果返回
⑤宏录制回放F6 热键 → main.ts → spawnPython(录制器) → pynput 监听鼠标键盘 → 事件写入 macros/*.json → F6 停止 → 列表更新 → 可转换为流程图
⑥视觉定位+经验学习Agent 需要点击"搜索按钮" → visual_locator.locate() → 查 experience_db(OpenCV matchTemplate) → 命中返回坐标 / 未命中→VLM API 分析截图→返回坐标→裁剪小图→存入经验库→后续离线复用
⑦语音对话麦克风 → WebSocket → voice/server.py → Whisper STT → LLM → Edge TTS → 音频二进制流 → 前端 AudioContext 解码播放 → 状态机 idle↔listening↔thinking↔speaking
