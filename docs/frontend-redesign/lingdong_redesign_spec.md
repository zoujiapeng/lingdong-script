# 灵动脚本前端重设计方案

## 1. 产品定位

新版前端不再把“流程图、伪代码、Agent、导入/录制、设置”当成并列工具页，而是重组为一个自动化工作台：

- Agent Cockpit：让用户用自然语言驱动电脑，并实时看到观察、动作、证据和风险。
- Automation Studio：让用户编辑可复用流程，重点是搜索式节点库、智能属性面板、证据验证门和失败恢复路径。
- Replay Lab：把一次成功操作转成 trace、WPS、FlowScript 或模板，明确哪些步骤可编辑，哪些必须原样 WPS 重放。
- Template & Knowledge：把成功记录、人工演示和常用流程沉淀成可搜索资产。
- Settings Center：按“连接、模型、执行、安全、计划任务、插件”分组，不再让高级项干扰普通用户。

## 2. 新信息架构

建议把顶部 tab 改为左侧模式栏 + 顶部 Command Dock：

1. 总览：最近任务、运行状态、模板建议、待处理失败。
2. Agent：自然语言任务输入、实时屏幕、动作时间线、证据面板。
3. 流程：可视化 FlowScript 编辑器。
4. 录制 / Replay：trace、WPS、人工演示、导入映射。
5. 模板：预设模板、我的模板、最近结晶、已验证模板。
6. 设置：模型、视觉、验证、快捷键、计划任务、系统控制、保险库、插件。

顶部 Command Dock 始终保留：搜索、运行、停止、验证、保存、导出、全局状态。这样用户在任何页面都能执行主要操作。

## 3. 主界面设计

### Agent Cockpit

目标：降低“AI 正在黑箱操作”的不确定感。

核心区块：

- 大任务输入框：支持自然语言、附件、窗口上下文和历史任务。
- 实时屏幕：显示 WinPilot iframe 或当前观察画面。
- 执行时间线：理解任务、观察窗口、执行动作、验证结果逐步展示。
- 证据面板：before / after / diff / 文件存在 / 截图。
- 安全护栏：窗口限定、文件写入、外部命令、敏感输入等用明确状态标识。
- 结晶动作：成功后提供“保存为模板”“导出 WPS”“导入流程图”。

### Automation Studio

目标：用户不需要先记住节点类型。

核心区块：

- 左侧搜索式指令库：默认给搜索框、推荐模板、常用动作，不默认显示所有节点。
- 中央画布：主路径垂直，失败恢复侧挂，验证节点必须显式可见。
- 右侧智能属性面板：先解释节点意图，再暴露参数；对高风险操作给风险提示。
- 下方执行条：显示当前节点、耗时、最近错误、证据入口。
- 节点卡片：标题、动作类型、关键参数摘要、状态、证据、输出端口。

### Replay Lab

目标：把复用链路解释清楚，避免用户误以为所有 WPS 都能等价转 FlowScript。

核心区块：

- 录制入口：实时 Agent trace、人工演示录制。
- WPS 脚本列表：支持原样重放、导入流程图、查看证据。
- 导入映射表：显示 WPS step 到 FlowScript 节点的映射结果。
- 占位提示：draw_strokes、run_detached、tray_click、未知 step、while/until 等保留 WPS 占位，并提示必须走原始 Replayer。
- 校准工作台：显示原始截图、动作目标、转换节点、验证建议。

## 4. 流程图编排规则

推荐使用固定布局语法，减少大图混乱：

- 主路径自上而下：开始 → 定位 → 执行 → 验证 → 输出。
- 成功路径继续向下，失败路径向右侧展开。
- 每个高风险动作后必须有验证门：截图、文件存在、窗口状态、OCR、颜色、区域变化。
- 重试最多 1–3 次，重试节点位于右侧恢复泳道，不要绕回主路径形成混乱环。
- 无法等价执行的 WPS 步骤保留为“WPS 占位节点”，并显示原始 payload 与原样重放按钮。
- 分组使用泳道：输入/定位、执行、验证、恢复、输出。
- 节点标题用用户语言，不用内部技术名；内部 type 放在小标签里。

## 5. 人性化使用建议

- 首次启动不要进入空画布，先问用户：“你想实时让电脑做事、录制演示，还是编辑已有脚本？”
- 运行前做自动体检：模型是否配置、WinPilot 是否在线、目标窗口是否存在、权限是否足够。
- 搜索指令库时支持自然语言：“点击用户名输入框并输入账号”，返回节点组合而不只是单节点。
- 错误提示给修复建议：不要只显示异常信息，要提示“检查窗口是否打开 / 是否需要先登录 / 是否缺少目标图片”。
- 保存模板时强制填写用途、适用软件、输入参数、成功证据、失败恢复策略。
- 执行完成后生成“复盘卡片”：总耗时、成功证据、重试次数、可复用建议。
- 设置页按用户频率折叠：常用放上面，高级视觉/插件/系统控制折叠。

## 6. 视觉语言

- 风格：深色高端、玻璃质感、动效边线、清晰状态芯片。
- 主色：Indigo / Cyan 渐变，成功用 Green，风险用 Amber，失败用 Red。
- 字体：继续使用 Outfit + JetBrains Mono；中文环境优先 PingFang SC / Microsoft YaHei fallback。
- 动效：执行中节点使用轻微边缘流光，不要全局闪烁；连接线运行时做一次方向性流动。
- 密度：默认中密度；高级用户可在设置中启用“紧凑模式”。

## 7. 前端实现拆分建议

建议新增或重构以下组件：

- `AppShell`：左侧模式栏、顶部 Command Dock、页面容器。
- `CommandDock`：全局搜索、运行/停止、验证、状态芯片。
- `AgentCockpit`：包裹现有 `AgentView`，外层增加任务输入、时间线、证据、护栏。
- `FlowStudioLayout`：组合 NodeLibrary、FlowCanvas、PropertyPanel、ExecutionBar。
- `SmartNodeLibrary`：把当前节点库改为搜索优先 + 推荐组合。
- `SmartPropertyPanel`：先解释节点目的，再渲染字段和风险提示。
- `ReplayLab`：替换当前简洁列表式导入页，加入映射和校准工作台。
- `EvidencePanel`：统一展示 trace、截图、文件、done check。
- `FlowAutoLayout`：统一流程排版规则。
