# WinPilot 能力演示 · 端到端矩阵

本矩阵记录「能力演示」覆盖的每一条能力，以及它**用什么独立证据**证明自己真的成功。

> 实测结果由 `scripts\能力演示-一键运行.py` 每次运行后自动生成到
> `output\能力演示\端到端矩阵.md`。本文是它的**完整说明版**（含节点语义与边界）。

## 一、证据分级（沿用仓库既有定义）

| 级别 | 含义 |
|---|---|
| C | 前端能编译为非 `legacy_flow`，结构/契约校验通过 |
| I | 本机 Runtime/集成测试真实运行（允许 test double） |
| **E** | **从真机运行，动作进入真实 Runtime，由 Runtime 之外的裁判（靶场 JSON）核验** |

本演示的两部分都追求 **E 级**：靶场是普通 Tk 窗口，把每次操作的事实写进外部 JSON，
报告逐项比对它。

## 五、明确边界（未纳入本次矩阵）

- **需要人工的节点**：`human_gate`、`REGION_SELECT`、`PROGRESS_INIT`（交互式框选）——
  需要人参与，不在自动矩阵内。
- **需要模型的节点**：`agent_goal`——需要大模型，不属于“离线”。
- **破坏性系统指令**：`关机 / 重启 / 注销 / 清空回收站` 等——故意不演示。
- **历史节点未迁移**：`loop`/`sub_script`/`web_browser`/`scene_condition` 等历史定义
  没有 canonical ARP，见 `docs\offline-flow-node-e2e.md`。
- **平台相关**：本机是单屏、125% 缩放；多显示器/混合缩放/负坐标需要额外硬件条件。
- **网络浏览器**：`browser_*` 系列本次不涉及（演示完全本地、不联网）。

## 六、本轮修复带来的矩阵变化

| 能力 | 修复前 | 修复后 |
|---|---|---|
| `SWIPE` 拖拽 | 落点被缩放 1.25 倍 → 点/拖不到 | DPI 感知 → 命中（通过） |
| `IMAGE_FIND/CLICK` 中文模板 | `cv2.imread` 中文路径失败 | `cv2.imdecode` → 可读（通过） |
| `IMAGE_FIND/OCR_FIND/REGION_WAIT/COLOR_CHECK` | DSL 参数未翻译 → 报错 | 补齐翻译（通过） |
| `POPUP_CLOSE` | 引用已删除类，永远失败；自绘窗口误判 | win32 按标题关窗，支持自绘（通过） |
